# 💰 CashFlow

Personal finance tracker with spending analytics & budget management.

## Features
- 📊 Interactive dashboard with pie & bar charts
- 💵 Income & expense tracking
- 🏷️ Category-based organization with emoji icons
- 📈 Spending trends & top expenses breakdown
- 🇮🇳 INR currency formatting
- 🌙 Light/Dark mode
- 📱 Mobile responsive
- 💾 Offline-first with sample data

## Tech Stack
- React 19 + TypeScript
- Vite
- Tailwind CSS v4
- Recharts
- Lucide Icons

## Getting Started
```bash
npm install
npm run dev
```
